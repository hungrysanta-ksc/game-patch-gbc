# 출처와 공개 범위

Final Fantasy III의 게임·음악·데이터·상표에 대한 권리는 해당 권리자에게 있습니다. 이 프로젝트는 비공식 팬 개발이며 권리자의 후원이나 승인을 받은 제품이 아닙니다. 원작 ROM·추출 음악·녹음·생성 ROM은 배포하지 않습니다.

분석 근거: [everything8215/ff3](https://github.com/everything8215/ff3/tree/1acef8117120ff891003de249b1a74bc8d94d674), 고정 커밋 `1acef8117120ff891003de249b1a74bc8d94d674`. 공개 디스어셈블리의 주소·설명을 입력 ROM 바이트와 대조했습니다. 해당 디스어셈블리나 게임 데이터의 복사본은 동봉하지 않습니다.

외부 빌드/검증 도구는 별도 설치 입력입니다. 해당 도구의 라이선스는 각 프로젝트를 따릅니다.

- [GBDK-2020](https://github.com/gbdk-2020/gbdk-2020), 4.5.0. 이 저장소에는 도구 바이너리·라이브러리를 동봉하지 않습니다.
- [Mesen Community Edition](https://github.com/nesdev-org/MesenCE), 검증 코어 출처. Mesen 코드·바이너리를 동봉하지 않습니다. `tools/Capture`는 해당 네이티브 인터페이스를 호출하는 프로젝트 작성 래퍼입니다.
- [Pan Docs Audio Registers](https://gbdev.io/pandocs/Audio_Registers.html), 하드웨어 출력 변환의 참고 자료.

이번 오디오 검증 프로젝트에는 기존 해리포터 한글 폰트나 게임 아트를 포함하지 않습니다. 실제 게임 한글 UI는 승인된 7×7 폰트 정책과 원작 메뉴 의미를 따르는 후속 통합 대상입니다.
