# 원작 표시 입력과 월드 타일 변경 판정

기준은 PR 21 병합 `76e8fa987fe5b37755f674c600eb5cb117f127f0`이다.
이번 경계는 원작의 플레이어/동행/NPC 표시 상태를 변경 요청으로 바꾸는 단계다.
GBC에서 실행하는 것은 **변경 영역 판정 함수**이며, 이 결과를 캐시 합성·업로드·한글 창까지
연결한 새 탐색 실행기는 아직 아니다. 원작 이동 속도/충돌 판정과 기존 탐색 빌드는 변경하지 않는다.

## 원작 입력의 생산자

`tools/composition-inputs.mjs`는 수정하지 않은 ROM의 다음 소비자를 실행한다.

| 경계 | 원작 소비자와 보존할 값 |
|---|---|
| 이동을 시작한 뒤의 픽셀 진행 | `3F/E5EB`, 중간 지형 전환 `E900`; 위치·서브픽셀·방향·속도 |
| 동행 초기 위치와 그림 선택 | `3B/BA15`, `BA5D..BAF1`; 일반맵 마스크, 직업/상태 및 동행 그림 은행/주소 |
| 동행 경로/픽셀 | `3D/B6DA`, `B78A` 및 내부 `B716`; 네 칸 방향/층 큐, 대기·프레임 난수·속도 |
| 플레이어/동행 표시 | `3E/D8D3`, `DB58`; 1픽셀 걷기 보정, 원작 4조각 순서·반전·팔레트·BG 가림 |
| 일반 NPC 표시 | `3B/B1EE`; 원작 슬롯/포즈/표시 조건, 프레임에 따른 일반 NPC 순서 |
| 팔레트 | `3A/9091`; 플레이어 0/1과 동행/NPC 2/3을 포함한 원작 OBJ 팔레트 전체 |

일반맵 29, world 2의 맵 87, 맵 139에 초기 객체 상태로 개발 진입한다. 방향과 속도를
이동 승인 직후의 입력으로 주고 원작 픽셀/동행 함수를 진행한다. 이는 충돌 검사나 정상 스토리
도달 경로의 재현이 아니다. 동행을 해당 지역에서 실제로 얻었다고 주장하지 않는다.
걷기 네 방향·서브픽셀·카메라 감기·숨김/재표시·NPC 순서와 표시 생략을 포함한 300상태다.
같은 상태 재요청, 3상태를 묶은 표시 제출, 별도 API 경계 입력도 구분한다.

각 상태는 카메라·무효화 세대와 14개 객체의 세계 좌표/표시 순서/그림 정체성을 보관한다.
정체성은 원작 그림 선택과 네 타일/속성의 12바이트이며, 충돌 가능한 짧은 해시로 줄이지 않는다.
일반맵의 걷는 16×16 객체 계약이다. 차량·큰 연출을 이 형식으로 조용히 잘라 넣지 않는다.
원작 동행 로직은 여기서 호스트의 6502 기준 실행이며, GBC 게임 실행기에 동행이 구현됐다는 뜻이 아니다.

## 화면 좌표 대신 월드 좌표에서 비교

카메라가 1픽셀 움직일 때 360셀을 다시 계산하는 방식은 사용하지 않는다. 1024픽셀 주기의
월드 좌표를 8×8 타일로 나누고, 미세 스크롤 가장자리를 포함한 21×19 영역을 유지한다.

- 카메라가 같은 타일 안에서 움직이면 스크롤/OAM 요청만 표시한다.
- 타일 경계를 넘으면 새로 들어오는 행/열을 표시한다. 큰 점프도 새로 보이는 영역을 빠뜨리지 않는다.
- 객체의 위치·자세·그림·팔레트/가림·숨김이 바뀌면 이전/새 사각형을 모두 표시한다.
- 원작의 NPC 순서가 바뀌면 여러 객체가 공유하는 타일을 표시한다. 같은 타일 안에서 불투명
  픽셀이 실제로 겹치지 않더라도 보수적으로 포함한다. 최종 캐시 입력이 같으면 합성을 생략할
  수 있다. 모든 객체 쌍을 반복 비교하는 비용 대신 두 번의 점유 비트마스크 순회를 사용한다.
- 맵/팔레트/배경 애니메이션의 의미가 바뀌면 호출자가 세대를 바꾼다. 현재 생산자에 연결하지
  않은 배경 변경을 자동으로 추측하지 않는다.

출력은 32×32 순환 지도에 대응하는 128바이트 비트마스크와 개수/스크롤/OAM/전체 무효화
정보다. 실제 VRAM 주소를 덮어써도 된다는 허가는 아니다. PR 21의 활성 타일 보호 및 준비
완료 후 전환 계약은 그대로 필요하다. 임의 표시 프레임을 생략해도 게임 논리 틱을 생략하면 안 된다.
함수는 비재진입이며 주 실행 흐름에서만 호출한다. 긴 작업에서는 행/열 및 두 객체 처리마다
호출자의 서비스 콜백으로 돌아가 오디오를 보충한다. 콜백은 판정 입력/결과/임시 공간을
바꾸거나 함수를 다시 호출하면 안 된다.

## 검증과 한계

호스트 기준은 월드 타일 전체를 독립적으로 열거한다. 별도로 원작 OAM 출력·그림·팔레트에서
각 타일의 최종 RGB555를 계산하여 실제 색 변화가 마스크 밖에 없는지 검사한다. 픽셀 계산은
변경 판정의 객체 사각형 필터를 재사용하지 않는다. 마스크를 지운 음성 검사는 실제 누락을 거부한다.
이는 원작 객체 순서의 논리 합성이다. NES/GBC의 줄당 객체 선택에 따른 탈락을 적용한 화면이나
실제 GBC 합성 화면의 검증으로 대체하지 않으며, OAM/색/VRAM 공존 예산은 별도 관문이다.

GBC 진단은 원작에서 만든 이전/현재 입력만 공급한다. 기대 마스크는 ROM에 넣지 않고 실행 후
독립 호스트 값과 비교한다. 원시 출력 133바이트, 가드, 실제 타이머 IRQ와 APU 쓰기를 관측한다.
시간 계측은 변경 함수 진입/반환의 에뮬레이터 시계이며 오디오 IRQ와 협력적 서비스 시간을 포함한다.
**이 시간에 원작 상태 생산, 캐시 검색·타일 합성, 업로드, VBlank 대기는 포함되지 않는다.**
PR 21의 전체 화면 응답 251ms와 같은 종류의 측정값으로 비교하지 않는다.

첫 셀별 처리와 객체 쌍 비교는 실제 오디오 큐 부족을 재현해 폐기했다. 비트마스크 바이트 단위
범위 처리·선형 점유 순회·협력적 서비스로 수정했다. 고정 도구의 중첩 포인터 스택 접근 비용도
확인하여 작은 패스로 분리했다. 원시 실패 관측은 로컬 `rejected-cell-loop/`, `rejected-pair-scan/`,
`rejected-bounds/`, `rejected-stack-pass/`에 남긴다. 판정 시간과 전체 표시 응답을 혼동하지 않는다.

```powershell
node tools/build-composition-input.mjs
node tools/verify-composition-input.mjs
node tools/verify-composition-input.mjs --idle
node --test tests/composition-input.test.mjs
```

`build/composition-input/report.json`은 원작 출처·입력/기대 출력·해시를,
`evidence/composition-input/`은 GBC 관측과 원작 표시 미리보기를 로컬에만 둔다.
미리보기는 호스트 원작 데이터 재구성이며 GBC 통합 화면 캡처로 표시하지 않는다.

| 검사 | 결과 |
|---|---|

| 변경 타일 수 | 원작 비전체 변경 요청 중앙값 21, 최대 53; 전체 무효화 399 |
| 판정 경과 시간 | 중앙값 25.879ms, 최대 169.922ms; 독립 버스 시계 최대 169.890ms |
| 원작 상태 쌍만의 시간 | 중앙값 25.879ms, 최대 109.863ms; 전체 최대는 별도 큰 카메라 점프 입력 |

| 부하 오류 | 오디오 지연·큐 부족, 은행 복원·가드·맵 작업 공간 손상 0 |
| 스택/전송 | 스택 미사용 하단 962바이트, 이 진단의 VRAM/DMA 전송 0 |
| 링크 비용 | 판정 ROM 은행 코드 2,075바이트, 고정 WRAM 끝 `$CAF9` |
| 호스트 검사 | 전체 41개 통과; 원작 픽셀 누락 음성 검사 포함 |
| 배포 소스 재현 | 허용 소스 250개만 별도 복사하여 ROM/빌드 보고서 동일 재현, 복사본의 GBC 부하 검증 통과 |

부하·무부하의 APU 쓰기 수와 순서 해시는 동일하다. 깨끗한 복사본에는 생성 자산·글꼴·번역을
옮기지 않고 원본 ROM과 고정 GBDK/MesenCore/.NET의 경로만 지정했다. 이번 진단에는 한글
자산 입력이 필요하지 않으며, 이를 전체 게임/한글 패키지의 오프라인 재현 완료로 세지 않는다.
빌드 보고서 SHA-256: `accf853c8f5c36f45b1066ea8b8f29bc1af74ad7969ca8daeca82afe7d7b6a08`.

타이머의 분해능은 0.244ms이며 IRQ·콜백 시간이 포함된다. 캐시 합성/업로드를 제외한 값이라도
원작 상태 쌍 최대가 100ms를 넘으므로 **현재 함수를 게임 틱마다 동기 호출하는 구조는 채택하지 않는다.**
다음 통합에서 요청 빈도·작업 분할·제출 합치기를 검증하되 원작 논리 진행은 유지해야 한다.
오디오는 원작 소비 이벤트 및 실제 레지스터 순서를 비교한다. 잡음/음색 개선이나 청취 승인을
통과했다는 뜻은 아니며 해당 작업은 후순위다.

진단 ROM SHA-256: `545f65966c7b9a3263750745b24660a0f0c7bd481c27f4c256fc95fbf917e3fc`.
MesenCore SHA-256: `1ba99d2c848e007c60cbd7fceca058440758eb44837a93a6724d29d72723c994`.
기존 탐색 실행기와 오디오 런타임 소스는 변경하지 않았다. 이 검증은 고정 에뮬레이터의
독립 진단이며 실기·다른 에뮬레이터 또는 정상 게임 진행 검증으로 대신 세지 않는다.

## 통합 메모리/한글 창: 확인된 충돌과 후보

이번 독립 진단의 두 입력은 520바이트, 출력은 133바이트, 점유 임시 공간은 128바이트다.
입력은 `$D800`과 `$DA50`, 점유 임시 공간은 유휴 전송 버퍼 `$D950`에 배치했다. 출력은
고정 WRAM이며, 맵 `$D000..D7EF`를 보존하는지 검사한다. 실제 창/필드 실행기와의 링크는
아직 별도다. 판정 중에는 이 버퍼를 읽는 DMA가 없어야 하며, 완료 뒤에 합성/전송에 반환한다.

| 자원 | 현재 충돌 | 다음 통합 후보/필수 조건 |
|---|---|---|
| 입력/출력 WRAM | PR 21 캐시 메타데이터는 맵 `$D000..D7EE`와 겹침. 새 판정 진단은 이 영역에서 분리 | 새 진단의 `$D800/$DA50` 입력, 고정 결과, `$D950` 임시 공간을 실제 창 닫힘/전송 완료 상태에 연결해야 함. 입력 생산·판정 후 임시 공간을 전송에 돌려주는 순서를 검증 |
| 이전 입력/캐시 메타데이터 | 창이 열리면 준비 버퍼를 돌려줘야 함; 새 월드 키는 PR 21의 불변 ID와 다름 | 이전 입력은 은행 저장 후 창 버퍼 반환. 은행 5 등 저장 공간의 정확한 키 형식·사용량·접근 시간을 확정해야 함. 매 프레임 안전 복사의 비용도 전체 응답에 포함 |
| BG/창 타일 주소 | 캐시 `LCDC=$93`, BG 0..127은 `$8000`; 기존 창은 글꼴을 은행 1 `$9000`, 지도 ID 0..127로 공급 | LCDC.4=0으로 통일하는 후보: 원작 기본 BG는 은행 0 `$8800`, 합성 BG는 은행 0 `$9000`, 한글은 은행 1 `$9000`. OBJ는 별도의 은행 1 `$8000` 영역. 실제 전송/감시 주소도 함께 바꿔 검증 |
| BG 지도 | 캐시가 `$9800/$9C00`을 교대로 점유; 창도 `$9C00`에 씀 | 대화 시작 전 제출을 비우고 활성 배경을 `$9800`에 정착시킨 뒤 `$9C00`을 창에 넘김. 닫힌 뒤 준비 지도는 무효화/복구하고 다음 커밋까지 보호 |
| 팔레트 | 창은 BG 팔레트 7을 덮어씀. NPC 전용 커널은 원작 OBJ 팔레트 두 개만 처리 | 표본 NPC 캐시의 공유 BG 팔레트는 최대 7개지만 플레이어/동행을 포함한 보장은 아님. 네 원작 OBJ 팔레트와 창의 동시 표현을 별도로 검증. 임의 색 감소로 해결하지 않음 |

이 표는 충돌 조사와 배치 후보이며 링크/실행 통합 합격표가 아니다. 창이 열린 동안 원작의
탐색 중단 조건을 유지하더라도 음악/효과음 생산·소비는 계속된다. 캐시/입력의 단계별 소유권과
기존 필드 상태·오디오·스택을 함께 링크하여 열기→페이지 갱신→닫기 후 원작 화면 복구를
통과해야 이 경계를 닫을 수 있다.

주소 방식은 [Pan Docs 타일 데이터](https://github.com/gbdev/pandocs/blob/master/src/Tile_Data.md)와
[LCDC.4](https://github.com/gbdev/pandocs/blob/master/src/LCDC.md#lcdc4--bg-and-window-tile-data-area)를 확인했다.
BG와 창은 같은 주소 선택 비트를 공유하고 OBJ는 영향을 받지 않는다. 직접 페이지와 curl이
실패하여 같은 명세의 GitHub 원문을 사용했다. 새 배치의 실기 합격을 주장하지 않는다.
