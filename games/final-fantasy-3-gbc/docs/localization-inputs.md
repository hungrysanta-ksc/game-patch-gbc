# 비공개 번역 입력 관리

사용자가 제공한 일본어 원문·한국어 번역 자료는 공개 저장소에 포함하지 않는다. 원본 압축 파일, 풀어낸 텍스트, 문장별 대응표와 콘텐츠에서 만든 파생 자료도 같은 정책을 따른다.

개발 PC의 `.local/private-inputs.json`이 비공개 입력 레지스트리의 위치를 안내한다. 해당 레지스트리에 원본 해시, 파일별 인코딩·해시, 언어 쌍의 키 일치와 중복 검사, 보관 경로, 미확인 사항을 기록한다. 개인 절대 경로나 문장·식별자 목록은 공개 문서에 복사하지 않는다. `.local/`은 Git 제외 영역이며 공개 소스 allowlist에도 없다.

현재 이 자료 중 **원작과 대조한 초반 대사 3개 묶음(번역 키 9개)**을 [한글 대사창 검증](text-window.md)에 연결했다. 나머지 문장의 대응은 미검수다. 원작의 한 문자열이 첨부 자료의 여러 키로 나뉘며, 일본어의 한자/가나와 줄 배치도 다르므로 키를 NES ID로 간주하지 않는다. 같은 키가 다른 파일 범주에 있을 수 있으므로 범주와 키를 함께 식별자로 사용한다.

비공개 대응 파일은 원작 ID·원시 문자열 해시·각 일본어/한국어 값의 해시·검수 상태를 고정한다. 번역 문구와 명시적인 원작 치환을 보존하고 줄 배치를 GBC 창에 맞춘다. 어느 입력이 바뀌면 빌드가 실패하므로 재검수해야 한다. 대응표와 글꼴 원본은 `local.json`의 `text` 또는 `dialogue` 설정으로 읽으며 저장소에는 포함하지 않는다. 기본 `story_mes` 외에는 명시적으로 선택된 `system`, `supplement` 범주만 허용하며 같은 키를 자동 탐색하지 않는다.

[NPC 대화 후속 검사](npc-dialogue.md)에는 기존 3묶음을 포함한 원작 문자열 13개 대응을 검수했다. 이름·아이템·금액 표식은 원작 제어 코드에 연결하고, 아이템명 뒤 조사 표식은 승인된 글꼴의 종성 정보로 처리한다. 첨부 한국어에서 빠진 원작의 한 절은 별도의 비공개 보충 번역으로 추가했으며 첨부 원본은 수정하지 않았다. 해당 보충 파일·해시·검수 대응도 비공개 입력 레지스트리에 기록한다. 검사 이름 4개는 첨부 시스템 자료에서 가져오며, 이름 입력/저장 형식까지 확정했다는 의미는 아니다.

적용 순서는 다음과 같다.

1. 지원 NES ROM에서 실제 문자열과 소비 루틴·제어 코드를 추출한다.
2. 비공개 자료의 일본어와 원작 문자열을 대조하고, 판본 차이·추가 항목·누락을 분리한다.
3. 확인된 대응에만 한국어 번역을 연결하고, 원작의 이름·숫자 치환과 제어 코드를 보존한다.
4. 채택된 7×7 한글 표시 방식으로 창·이름 입력·치환·저장 경로를 검증한다.

본문·번역 데이터를 게시할 권한이 생겼다고 추정하지 않는다. 향후 배포 형식에 번역 자료가 필요하면 사용자의 현재 비공개 지시를 유지한 상태에서 입력/배포 방식을 별도로 정한다.

이벤트 이동 검사에서는 원작 이벤트 118의 문자열 두 개를 추가 대조했다.
별도 비공개 `event` 입력에 기존 대응과 두 새 대응을 보관한다. 첨부 한국어
문구를 유지하며 페이지 표식만 창 배치에 연결한다. 기존 대사 입력은 변경하지 않는다.

진열 선택 후속에서는 원작 `0622/0623`의 방향별 행동명을 비공개 `supplement` 대응에 추가했다.
제공된 시스템 번역에는 두 방향을 합친 명령만 있어, 원작의 전진/후퇴 구분을 보존하는
별도 보충 번역과 원문/번역/대응 해시를 기록했다. 제공된 번역 원본은 수정하지 않았으며
보충 파일도 공개 allowlist에 넣지 않는다.
