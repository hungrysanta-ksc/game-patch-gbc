**현재 위치: 기반 검증을 확보하고, 일반맵의 부분 탐색·한글 대화·NPC 이벤트를 통합한 단계.**
첫 정상 게임 진행, 전편, 배포 패키지는 아직 완료되지 않았다.

이번에는 [화면 소유권 인계](scene-video-handoff.md)를 필드·전투 표시기에 연결했다.
공통 텍스트/오디오는 유지하고 VBlank·OAM·전투 LCD 콜백을 안전하게 교체한다.
개별 표시기의 중단/재진입과 원작 오디오 연속성을 검사했으며, 필드 열 전송 끝 처리와
화면 갱신을 미루던 오디오 추가 생산도 수정했다. 실제 합친 링크는 고정 RAM/ROM과
자산 뱅크 충돌을 확인했다. 다음은 공통 배치 수정과 실제 단일 ROM 왕복이다.
아직 별도 실행기이므로 R2 0/8·제품 0/3은 유지한다.

앞선 [장면 자원 등록부·원작 인계 검사](scene-resource-contract.md)에서는
19개 저장 범위와 10개 소유권·52개 관련 소스를 등록하고, 원작의 문맥/인터럽트/가방
소비자를 512개 경계 사이클로 실행했다. 사운드 DP를 복구 대상에서 제외하고 전투 후
지속 상태를 유지하는 규칙을 검사했으며, 과거 WRAM 3 필드 예약의 충돌을 자동 검출한다.
현재 GBC 화면/오디오는 변경하지 않았다. 단일 ROM 왕복 관문은 명시적으로 미통과이며
R2 0/8·제품 0/3도 유지한다. 다음은 필드 문맥 추적과 공통 부팅·표시 인계/합친 링크다.

앞선 [필드/전투 수명 재점검](field-battle-lifecycle-review.md)에서 독립 실행기의
WRAM 예약·작업 공간·콜백·진단 파티 상태 공급 차이를 확인했다. 인카운터는 아직
전투로 연결되지 않는다. 원작은 그래픽을 교체하면서 문맥을 보존하며, 현재의
전투 내부 캐시는 장면 간 보존을 보장하지 않는다. 추가 단독 마법 최적화보다
같은 ROM의 필드→전투→필드와 재진입 검증을 우선한다. 이번은 정적 감사와 계획
수정으로 실행 완료 수를 늘리지 않는다. R2 0/8·제품 0/3은 그대로다.

## 제품 관문: 0 / 3 통과

이 수치는 아래 세 가지 사용자 경험의 완료 여부다. 전체 개발 공수 0%라는 뜻이 아니다.

| 관문 | 상태 | 통과 조건 |
|---|---|---|
| P1 첫 정상 진행 | 미통과 | 개발 직행 없이 새 게임·이름→첫 실제 전투/동굴/보스/크리스털·직업 해금→원작에서 저장 가능한 곳의 저장·재개 |

| P3 배포 | 미통과 | 원본 ROM과 명시한 허용 외부 입력으로 깨끗한 오프라인 재현 빌드, 공개 제외 정책, 음색 및 독립 에뮬레이터/실기 검증 |

문법상 지원하는 이벤트 ID는 254개 해석 가능 슬롯 중 66개다. 빈 스크립트·별칭도 포함하며,
66개 스토리 이벤트를 모두 정상 플레이로 검증한 수치가 아니다. PR 15의 대표 이벤트 실행은
118을 두 번 완료한 것이다. 포인터 슬롯 FE/FF의 미해결도 opcode FE/FF 구현과 구분한다.
일반맵의 전수 자산 표시는 해당 지역의 트리거·전투·스토리 완료를 의미하지 않는다.
