# 전체 작업 진척

기준: 2026-11-24, [R2 전투 상태 합성·전송과 적 후퇴](battle-scene-composition.md) 반영.
이번 작업의 기준 커밋은 PR 29 병합 `a0c407d5db6f4973056e8e7b0f323946b536957a`이다.
PR 15 병합 `aeeedf69c071a597c06237c0e6ebcb0ce6440264`의 고정 기준선은 회고에 보존한다.
[회고](retrospective-pr15.md) / [현재 작업 순서](implementation-roadmap.md).

**현재 위치: 기반 검증을 확보하고, 일반맵의 부분 탐색·한글 대화·NPC 이벤트를 통합한 단계.**
첫 정상 게임 진행, 전편, 배포 패키지는 아직 완료되지 않았다.

```text
기반 검증 ── 부분 탐색 통합 [현재] ── 첫 정상 진행 ── 전편 진행 ── 배포 검증
```

이 선은 단계 표시이며 작업량 비율이 아니다. 아직 전투/공유 규칙/월드/전체 이벤트의 실제 구현량을
산정하지 않았으므로 전체 공수의 완료율을 숫자로 추정하지 않는다. 테스트 10,826건이나
PR 15개를 게임 완성률로 환산하지 않는다. 아래의 검증된 범위와 제품 관문으로 진척을 표시한다.

## 제품 관문: 0 / 3 통과

이 수치는 아래 세 가지 사용자 경험의 완료 여부다. 전체 개발 공수 0%라는 뜻이 아니다.

| 관문 | 상태 | 통과 조건 |
|---|---|---|
| P1 첫 정상 진행 | 미통과 | 개발 직행 없이 새 게임·이름→첫 실제 전투/동굴/보스/크리스털·직업 해금→원작에서 저장 가능한 곳의 저장·재개 |
| P2 전편 진행 | 미통과 | 같은 공통 실행기로 새 게임부터 엔딩, 필수 분기와 전멸/취소/저장 복원, 전체 한글 소비자 검증 |
| P3 배포 | 미통과 | 원본 ROM과 명시한 허용 외부 입력으로 깨끗한 오프라인 재현 빌드, 공개 제외 정책, 음색 및 독립 에뮬레이터/실기 검증 |

문법상 지원하는 이벤트 ID는 254개 해석 가능 슬롯 중 66개다. 빈 스크립트·별칭도 포함하며,
66개 스토리 이벤트를 모두 정상 플레이로 검증한 수치가 아니다. PR 15의 대표 이벤트 실행은
118을 두 번 완료한 것이다. 포인터 슬롯 FE/FF의 미해결도 opcode FE/FF 구현과 구분한다.
일반맵의 전수 자산 표시는 해당 지역의 트리거·전투·스토리 완료를 의미하지 않는다.

## 다음 갱신 기준

현재 실행기에 R1의 재배치/저장 접근 계약을 적용했다. R2의 밀집 정지 입력에는 손실 없는 합성 후보를 확보했다.
정적 사전 변환·128슬롯 캐시·활성 타일 보호·전체 화면 전환을 원작 22개 진단 상태에 연결했다.
작은 NPC 변화에도 남는 지연은 정상 이동에 부적합하며, 기존 탐색 실행기를 교체하지 않았다.
후속으로 원작 함수에서 만든 플레이어/동행/NPC 300상태와 GBC 변경 판정 경계를 추가했다.
카메라를 월드 타일 기준으로 나누고, 위치·자세·순서·숨김을 변경 마스크로 만든다.
이것은 실제 GBC 합성/업로드까지 이어진 새 이동 실행기가 아니다. 동행 논리의 GBC 이식도 남아 있다.
후속 [네 원작 OBJ 팔레트와 한글 창](composition-window.md)의 주소·지도·임시 버퍼 전환은 대표 장면에서 연결했다.
빌드 시점의 원작 입력 공급이며 실시간 변경 마스크/게임 실행기의 통합은 남아 있다. 전체 응답도 정상 이동에는 느리다.
후속 전투 조사에서 보스 206 초기 타일 공급을 해결했지만 적의 보조 OBJ와 큰 마법의 공존 실패가 남았다.
후속 합성 후보의 동기 요청 지연을 선행 준비와 원작 시점의 VBlank 게시로 분리했다.
대표 마법의 자동 재생/효과 지우기와 한글·오디오 공존을 검증했다. 후속 호스트 검사에서 원작 편성
710개 최소/최대 수량 입력의 위치·타일맵·투사체 각도를 대조하고 314개는 미해결로 기록했다.
대표 8편성·197상태 중 60상태가 현재 합성기의 OBJ 한도로 실패했다. 일반 마법 256개 대상 마스크,
아군→적 물리 호출 32개, 소환 24변형의 대상 분기를 검사했으며 시전 자격/전용 연출은 미구현이다.
후속 영상 조사에서 등장·행동 창·HP/숫자·아이템·승리/레벨업·필드 복귀를 확인했다.
원작 155분기 슬롯과 6행동 스크립트, 강제 5창의 밑그림 복원, 8대상 숫자 32프레임을 검사했다.
원작 8×8 직접 복사 후보는 숫자 32+아군 24=56조각이며 GBC의 최적 필요량은 아직 미확정이다.
후속으로 원작 등장 본문의 적/메뉴 이동과 보스 CHR 이동, 상태 우선순위 65,536입력과
37프로필·666상태 전환의 복원을 실행 검사했다. 아이템 512입력의 분기와 41표시 프로필의
대상 위치·사용자 복귀·숫자 CHR 복원도 검사했다. 새 GBC 표시/음악 실행이나 HP 계산 검증은 아니다.
석화 BG, 혼란 이동/해제, 아이템 예약/반환/대상 예외를 기존 8개 시나리오의 필수 조건에 포함했다.
이어 같은 원작 VRAM/OAM의 일반/백어택 109관측을 GBC에 공급했다. 173타일 입력을 위해 활성/다음 BG 은행을
분리하고 한글 창의 은행 대여/복원과 오디오 공존을 검사한다. 기본 8픽셀 적 후퇴와 효과 기준점 이동도 반영했다.
편성 3의 등장 완료 후 겹침은 해소했지만 백어택 등장 2상태와 가장자리 편성의 배치는 남는다.
이것은 실시간 전투 실행기가 아니며 원작 속도, HP/행동 메시지/숫자와 나머지 연출의 통합은 미완료다.
다음은 개별 편성 최적화에 앞서 전체 표시 수명을 추적하고, 한글/HP/커서/메시지/효과/오디오를 함께
실행하는 8개 통합 시나리오의 예산을 측정한다. 이번 통합 통과는 0/8이다. 실패 편성과 공급 문제,
탐색 캐시의 모드별 소유권·실시간 응답도 같은 계약에 포함한다. 유한 그림의 진단을 정상 전투 구현으로
세지 않으며 R2는 열린 상태다. 제품 관문은 계속 0/3이다.
R2가 닫힌 뒤 R3 공유 규칙·첫 전투 계산으로 진행한다. 이후 탐색 소비자와 메뉴/전투를 연결하면서 실제 모드 전환을 검증하고 P1을 통과한다.
매 PR마다 기준 커밋, 기능 상태, 미해결, 관문 결과를 갱신하되 과거 회고의 기준선을 덮어쓰지 않는다.
함수 검증→진단 ROM→정상 입력 통합→전체 도달 경로 검증을 구분해 기록한다.
