# 공격 프레임의 실제 게시 대기

기준은 PR 81 병합 `1103f9eec880cca2a4d679f485ead3475561cbbf`다.
원작 프레임·도트·숫자와 효과음 요청을 그대로 두고, 준비된 OAM의 불필요한
다음 VBlank 대기를 줄인다. 오디오 생산량·예약량·VM·변환 정책은 변경하지 않는다.

## 원작 호출·자원 수명

- `2F/B24F..B258`: 전진, `A9CF` 직업 그림, `A8EA` 양손 무기 로드,
  `AEF0` 무기 애니메이션, 이후 `B25B` 후퇴 순서다.
- `33/A365..A3DA`: 공통 kind 1/2의 명중 횟수별 8프레임 루프에서
  `A3C8 → 3F/F8B0`으로 준비된 그림을 게시한다.
- `3F/F8B0`: `FB80`의 NMI 대기, `F8AA`의 `$4014` OAM DMA,
  `F897` 팔레트와 `F8CB` PPU 레지스터 갱신 순서다. `FB57..78`의 전투 NMI가
  대기 플래그 `$05`를 해제한다. 화면 생산자와 게시 경계는 분리되어 있다.
- `3F/FB30..56`의 전투 스캔라인 IRQ는 `$AA|$A9` 로딩 중이 아니면
  `FB52 → FAF2`로 사운드를 갱신한다. `FAF2..FB16`은 효과음 요청 `$7F49`,
  사운드 은행 전환과 `36/8003`, 원래 은행 복귀를 처리한다.

GBC는 기존 생산자가 준비한 이중 OAM shadow의 소유권을 `party_pending`으로
게시자에 넘기는 구조를 유지한다. 원작 IRQ와 동일한 시간을 흉내 내기 위해 화면을
재합성하지 않는다. GBC의 TIMA 오디오 소비·전경 생산·VBlank 게시 구조는 유지하고,
실제 전송 가능 시간을 지나치게 좁힌 조건만 수정한다.

## 원인과 변경 범위

기존 완료 카운터의 최대 간격은 106.689ms였다. 읽기 전용 실행 훅으로 준비 완료,
`FF46` DMA 시작, pending 해제, 호출자 프레임 카운터 갱신을 따로 측정하니 실제 DMA
간격도 100.736ms였다. 첫 칼질 프레임 9와 다음 프레임 10은 게시자 진입 LY가
각각 `146,144`였다. LY146에서 거부되어 다음 VBlank의 LY144까지 기다린 것이다.

`FF3_EFFECTS`의 실행 중 행동이며 `terrain_dma_mask==0`인 경우에만 진입 상한을
LY145에서 LY148로 넓힌다. 등장·비행/배경 갱신처럼 지형 DMA를 동반하는 경로는
기존 LY145 제한을 유지한다. OAM shadow 주소, 원작 반복 횟수, 페이지 교체와
DMA 중 인터럽트 마스킹은 그대로다. 지형 전송 마스크는 새 RAM을 만들지 않고
기존 변수를 읽는다.

[Pan Docs OAM DMA](https://raw.githubusercontent.com/gbdev/pandocs/master/src/OAM_DMA_Transfer.md)는
double-speed에서 160 M-cycle/320 dots의 DMA와 HRAM 실행을 명시한다.
허용 창을 무조건 VBlank 끝까지 넓히지 않았다. 실제 DMA 시작 LY150 이하와 Mode1,
완료 시점의 Mode1을 별도로 검사한다. 이 검사는 지정된 MesenCore의 실행 증거이며
실기 승인이나 모든 에뮬레이터의 일치 주장은 아니다.

## 계측과 회귀 관문

`battle-publication-profile.mjs`는 고정 컴파일러의 listing과 링크 심벌로 기존
게시자 진입 주소를 구하고, ROM의 LY/SCX/pending 읽기 명령 바이트를 확인한다.
실행 ROM에 진단 명령을 삽입하지 않는다. 프레임별 비용·네 시각·진입 LY·DMA/완료 LY를
같은 로그 행에 기록하여 에뮬레이터 로그 제한에 따른 누락을 방지한다.
83회의 순서와 경계 짝, DC/DD shadow, 안전한 DMA 시작/완료를 검증한다.
고정 최대 명중 자동 조건의 실제 DMA 최대 간격은 90ms 미만이어야 한다.
`--baseline`은 이전 ROM 비교용으로 이 성능 상한만 면제하며 안전 검사는 유지한다.

짧은 `--action-only`는 타이밍 조사이며 7,200틱 오디오 승인이나 화면 픽셀 검증을
대체하지 않는다.
