# 원작 사운드 변환 규칙 · 첫 검증 단계

이 문서는 현재 입력 ROM 한 리비전에만 적용합니다. 모든 파일 오프셋은 16바이트 헤더를 포함합니다. 원본 전체 SHA-256을 검사한 후 실행합니다.

## 추출과 원작 실행

- 원작 드라이버: bank `36`, CPU `$8000` 초기화 / `$8003` 갱신. 파일 `$6C010..$6CC86`.
- 음악 요청: `$7F43` 곡 ID, `$7F42=1`. 효과음 요청: `$7F49=$80|ID`.
- 곡 포인터 표: 파일 `$6E010`(ID 00–18), `$70010`(19–2A), `$6CC87`(2B–36), `$733BE`(37–3A), `$13410`(3B–40). 숫자는 16진수입니다. 헤더는 5개 채널 포인터, `$FFFF`는 비활성 경로입니다.
- 효과음 포인터 표: 파일 `$6D2D5`, 97개 항목, 각 헤더는 pulse 2 / noise 경로 포인터입니다. 원작 분석 문서의 오프셋 오기를 그대로 사용하지 않고 bank `36/$92C5`에서 계산했습니다.
- `Driver6502`는 PC에서 원본 명령 바이트를 실행합니다. PPU/APU 파형·CPU 사이클 에뮬레이터가 아닙니다. 알 수 없는 opcode/mapper 쓰기는 중단합니다. 매 틱 `$4000..$4017` 쓰기와 `$7F40..$7FFF` 상태를 기록합니다.
- 원작 드라이버의 BGM/SFX 점유·복원과 소프트웨어 엔벌로프가 그대로 실행됩니다. 별도 작곡·수동 악보·일반 MIDI 변환을 사용하지 않습니다.

## GBC 출력

| NES 출력 | GBC 출력 | 현재 변환/제약 |
|---|---|---|
| pulse 1/2 | CH1/CH2 | 타이머에서 실제 음정을 계산해 GB 주파수로 반올림; 듀티와 소프트웨어 음량을 전달 |
| triangle | CH3 | 32샘플 삼각파; NES의 고정 음량과 GB 채널 혼합 특성은 동일하지 않음 |
| noise | CH4 | 가장 가까운 LFSR 클록을 선택; 시퀀스·짧은 모드 음색 차이 존재 |
| `$4011` 직접 DAC | 임시 CH4 버스트 | 약 0.49 ms 동안 CH4를 빌리는 후보; 기존 노이즈와 충돌 가능, SELECT로 비활성화 |

NES 타이머 `t`에 대해 GB 주파수 값은 `2048 - round(2097152 × (t+1) / 1789773)`를 0–2047로 제한합니다. NES pulse/triangle과 GB pulse/wave의 분주비 관계를 반영합니다. NES 하드웨어 sweep은 120 Hz 상당의 두 갱신/소스 틱으로 근사합니다. 정확한 서브프레임 APU 스케줄링은 아직 구현하지 않았습니다. GBC 음량 변경은 재트리거를 요구하는 현재 방식에서 위상 차이를 만듭니다.

곡 07/20/28/2A는 다섯 번째 경로가 살아 있습니다. 원작 `36/8310`의 `$4011` 비영 쓰기를 팝 이벤트로 보존합니다. 이것을 DPCM 샘플 재생이나 없는 채널로 오해하지 않습니다. CH4 버스트는 청취 비교용 구현이며 품질 채택 결정은 별개입니다.

NES 약 60.098 Hz와 CGB 약 59.7275 Hz를 맞추기 위해 CGB VBlank당 `10062/10000`개의 소스 틱을 소비합니다. 가끔 2틱을 처리하며, 오디오 패킷과 틱 카운터는 `audio_busy` 구간을 벗어난 뒤 관측합니다. 12바이트 패킷을 1–255틱 RLE로 압축하되 재트리거가 있는 틱을 합치지 않습니다. ROM 은행 경계는 연속 스트림 리더가 처리합니다.

## 독립 실행 비교

원본에서 사용하지 않는 최상위 고정 은행 `$E000` 부분과 벡터만 로컬 검증 코드로 교체해 NES harness를 생성합니다. 원본 사운드/음악 은행은 그대로 둡니다. 초기 RAM을 지우고 원본 초기화 루틴을 호출한 뒤 NMI마다 같은 드라이버를 갱신합니다. NMI 카운터는 `$2002` 폴링의 vblank 누락 문제를 피합니다.

Mesen 네이티브 코어로 NES harness를 실제 실행해 원작 상태 192바이트를 PC 추출기 상태와 비교합니다. GBC에서는 디코딩한 패킷 11바이트를 해당 틱의 생성 데이터와 비교합니다. 소비 후 지우는 트리거 바이트는 이 상태 비교에서 제외합니다. 따라서 이 검사는 원작 의미 해석/스트림 소비의 근거이지 파형의 완전 일치 증명이 아닙니다. 관측 사이에 지난 틱을 모두 관측했다고 계산하지 않습니다.

녹음 래퍼는 Mesen 관리 어셈블리의 인터롭 레이아웃을 사용해 NES 채널 음량을 명시적으로 100으로 설정합니다. 헤드리스 코어의 기본값은 UI 설정과 다를 수 있습니다. 디버거가 `IsExecutionStopped`뿐 아니라 `IsPaused` 상태까지 도달해야 다음 명령을 보냅니다. GBC 갱신 중 정지했다면 짧은 PPU 스텝으로 갱신이 끝난 시점까지 진행합니다.

## 이 단계에서 보장하지 않는 것

전 곡의 완전한 루프/종료, 모든 조합의 효과음 중첩, 임의 시점 일시정지/페이드/템포 변경, GBC 실기 음색, 실제 전투와 맵 화면 부하를 함께 실행하는 예산은 미검증입니다. 유한 이벤트 스트림을 전체 게임에 그대로 늘리는 것은 최종 설계가 아닙니다. 원작 음악 명령/루프를 보존하는 작은 GBC 실행 계층과 분리된 출력 백엔드로 진행합니다.
