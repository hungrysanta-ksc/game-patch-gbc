# 사운드 판단 및 보류 항목

## 2026-11-22 청취 피드백

사용자가 VGZ 변환 GBC 테스트 ROM을 들어본 뒤, NES APU 재생에 비해 잡음이 많이 섞여 들리며 음색 조정이 필요하다고 평가했다. 대상은 `ff3-vgz-timed.gbc`, SHA-256 `6f4fc6a89cc7a04ec0fbd9f39e78262d98da966dd71b9dc9e7a330cb3618618e`다.

**사용자 결정: 음색 조정은 뒤로 미루고 원작 이식을 계속한다.** 이는 현 음질을 최종 승인하거나 원인이 GBC 하드웨어라고 확정한 결정이 아니다. 현재 타이밍 검증 통과와 청취 품질 미해결을 별도로 유지한다. 이번 작업에서는 음색 상수·음량·듀티·파형·노이즈 변환을 변경하거나 새 녹음을 만들지 않는다.

후속 음색 조사 후보는 음량 변경 때 재트리거/위상 재시작, NES/GBC duty·노이즈 차이, CH3 파형과 채널 혼합, `$4011` 타격음의 CH4 차용 및 원래 노이즈와의 충돌이다. 후보는 아직 확인된 원인이 아니다. 원작 호출·효과음 점유/복원과 음악 명령 해석기를 먼저 확보하고, 같은 음악·같은 요청 시나리오로 원인을 분리한다.

원본 ROM·VGZ·생성 ROM·녹음·번역 자료는 계속 비공개 로컬 입력/산출물로 유지한다.

## 2026-11-23 재확인: 음질 개선은 후순위

사용자는 현재 음원에 노이즈가 많다고 다시 평가했고, 다른 변환 방식의 검토도 요청했다.
이번 피드백에는 ROM 파일명/해시가 특정되지 않았으므로 위 VGZ 기준선이나 최신 native ROM에
임의로 귀속하지 않는다. **이식 작업을 계속하고 음질 개선은 후순위로 둔다.**

R2 표시 예산과 R3–R6 핵심 게임 경로를 먼저 진행한다. 음질 작업을 시작할 때 실제 청취 대상을
해시로 고정하고, 같은 곡·구간·효과음 요청으로 다음 후보를 비교한다.

1. NES APU 기준과 현재 GBC 출력의 채널별 비교: 원곡의 의도된 노이즈, 변환 오류,
   재트리거/위상·채널 점유, 에뮬레이터 출력 문제를 구분한다.
2. 원작 음표·반복·템포·페이드 실행기는 유지하면서 GBC 음원 배치/출력 변환을 개선하는 방법.
3. 원작 명령을 빌드 시 GBC용 음표·악기 이벤트로 변환하는 방법과 기존 VGZ 레지스터 변환의 비교.
   파일 형식만 바꾸는 것이 잡음을 해결한다고 가정하지 않는다.
4. CH3 파형/짧은 샘플 사용 등 다른 재생 방식은 CPU·ROM·채널 충돌·화면 동시 부하를 함께 평가한다.

후보는 조사 계획이며 채택 결정이나 확인된 원인이 아니다. 같은 원작 진행 시점과 효과음 복원을
보존하고 사용자 청취 비교를 거친 뒤 채택한다. 타이밍/큐 검증 통과를 음질 승인으로 대체하지 않으며,
출시 전 음질 관문은 유지한다. 이 기록에서는 변환 상수나 새 녹음을 변경/생성하지 않는다.

## 2026-11-25 전투 진입 예산과 채널 확인

전투 돌입 준비에 약 500ms는 허용하지만, 오디오 계산에서 발생하는 지연은 별도로 줄인다.
[상주 준비 비용과 원작 실행 대조](battle-preparation.md)에서 효과음 97개 슬롯의 펄스2/노이즈
점유와 전투곡 자체의 4011 DAC 타격음을 확인했다. 부족한 다섯 번째 경로를 효과음 전용으로
가정하지 않는다. 원작 효과음 우선권·복원과 전투곡 DAC가 겹치는 구간을 청취 비교에 포함한다.
현재 CH4 차용 정책은 변경하지 않았으며, 출력 바이트/시간 일치는 음질 승인과 별개다.
