# 적이 아군에게 쓰는 일반 마법의 실제 표시

PR 89의 공통 프레임 커널을 실제 V6 전투 화면의 요청 29에 연결한다.
이번 범위는 **적 시전자 → 아군 대상, 보통 마법 본체 0, 반사 없음**이다.
정상 메뉴·마법 계산·MP 소비·AI를 연결했다는 뜻은 아니다. 아군 시전/발사,
적 대상, 반사, 특수 19분기 및 소환 24슬롯은 명시적으로 미지원이다.

## 원작 호출과 수명

- `2F/B15E`의 적 시전자 플래그는 아군 전진·직업 그림 로드를 건너뛰고
  `33/BAFD → B91A → B937`로 간다. `B09B`도 적 시전에서는 자세 재생을
  생략한다. `B276` 발사는 아군→적 조건에만 있다.
- `AC35`는 소리 FF 정지와 아군 자세 복구 후 `AC40`에서 한 번 기다린다.
  `B68D/B589`는 그래픽 요청 07/08과 효과 팔레트를 준비한다.
- 대상 비트는 상위부터 순서대로 소비한다. `B6F3`의 효과음 pending은
  NMI `3F/FAF6..FB05`가 CA|80으로 전송한다. 프레임은 `B711/B7AD`에서
  네 번 유지하고 대상 끝 `B70E` 한 번, 본체 끝 `BB12` 한 번 기다린다.
- 실제 `B15E`를 실행하여 위 대기 시점의 OAM·CHR·팔레트를 관측한다.
  자료 로더의 추가 NMI 전송 대기는 연출 유지 프레임 수와 구분한다.
  원작 프레임 수 보존만으로 실제 초당 속도가 같다고 주장하지 않는다.

## GBC에서 달라지는 부분

원작의 최대 36개 8×8 효과 슬롯과 아군을 그대로 OBJ로 합치면 40개를 넘는다.
[Pan Docs OAM](https://gbdev.io/pandocs/OAM.html)의 전역 8×16 모드에서
원래 8×8 두 장을 세로로 묶는다. 각 반쪽의 반전은 원래 비트플레인에 적용하여
도트를 줄이거나 다시 그리지 않는다. 효과는 최대 18 OBJ다.

일반 명중 본체 동안 아군 자세는 고정이므로 기존 숫자 소유자의 제한된 동결 기능을
재사용한다. 아군의 해당 픽셀만 signed BG에 잠시 보존하고 아래쪽 발과 잔여 색상
OBJ는 유지한다. 남은 OBJ도 투명한 아래 절반을 붙인 8×16으로 바꾼다.
화면 전체 합성/프레임 동영상 자산은 사용하지 않는다. 36개 raw OAM은 비교용
원작 좌표로 유지하고 GBC 게시 때만 투영한다. 48×48 전체 범위를 고정 이동하여
화면 밖의 도트를 자르지 않는다. 아군은 원본 크기, 적은 기존 28×28이다.

줄별 검사에서는 144줄마다 전체 OBJ를 재검색하지 않는다. 패턴 전송을 마친
작업 버퍼를 144바이트 줄 카운터로 재사용하고 각 OBJ가 차지하는 16줄만 센다.
타일쌍 사이와 OBJ 사이에 오디오 생산을 재개한다. 제한은 그대로 40개/줄당 10개다.

자원 소유권:

| 자원 | 범위와 복구 |
|---|---|
| 효과 이중 버퍼 | VRAM 1 `$8000..847F`, 2×576바이트; WRAM 4 앞 1152바이트에 원본 보관 |
| 잔여 OBJ의 8×16 쌍 | VRAM 0 `$84A0..859F`, 256바이트; WRAM 4 다음 256바이트에 원본 보관 |
| 아군 동결 | 기존 signed BG와 WRAM 3 복구 계약; 효과 준비와 동시 실행하지 않음 |
| 작업 공간 | `$D200` 공용 704바이트; 패턴·잔여 OAM·한 글리프와 전송 후 줄 카운터 |
| 코드/불변 자료 | 은행 64 프레임 커널, 65 표시 실행기, 66..69 그래픽/팔레트 88레코드 |

VBlank에서 OAM과 전역 OBJ 크기를 함께 게시한다. 종료 시 VRAM 1을 먼저 복원하고,
잔여 OBJ가 참조하는 VRAM 0은 그대로 둔 채 8×8/아군 복구를 게시한 다음 복원한다.
따라서 전송 중인 타일을 현재 OAM이 읽지 않는다. 원작의 사용하지 않는 시전 그림
05/06과 숫자 그림 재적재는 GBC의 별도 상주 자원 소유권으로 대체한다.
미지원 조건은 자원을 빌리기 전에 실패한다. 같은 동안 다른 애니메이션 소유자는 실행하지 않는다.

## 검증 명령과 남은 관문

`node tools/build-battle-party-oam.mjs --effects`로 실제 ROM을 만들고,
`node tools/verify-battle-magic.mjs`에 `--back`, `--status`, `--auto`를 조합한다.
`--flips`는 코드/접두사에 의한 좌우·상하 반전 네 조합을 별도로 실행한다.
`--reuse`는 동일 ROM 해시의 저장 관측만 재검사한다.
`node --test tests/battle-magic-video.test.mjs tests/battle-magic-frames.test.mjs tests/battle-animation.test.mjs`는
원작 대상 순서·대기·효과음과 프레임/시퀀스 자료를 검사한다.

화면 검사는 실제 에뮬레이터 PNG, 독립 CGB 화면 재구성, 원작 NES 타일 투영을
각각 비교한다. 마지막 화면·빌린 VRAM·전역 OBJ 크기도 복원되어야 한다.
오디오는 실제 요청 시점의 원작 APU/변환 출력 해시, 7,200틱 전체와 부족/지연을
검사한다. 음색 승인이나 실기 검증과는 별개다. 원시 관측/추출물/ROM은 비공개다.

고정 ROM SHA-256:
`21fbe3662df27bcab67e8a384a31b2fd4163dd4be9268990145b9bdf1897c48e`.

정면과 백어택/상태 혼합의 8조건에서 **444화면**(마법 380 + 원작 선행 점멸 64)이
일치했다. 각 방향에 밀집 29/36, 아군 전체 0, 명중 없음 1을 포함한다. 원작 공격
속성표 `30/98C0+id*8+6`에서 모두 보통 본체 0임을 확인했다. 전체 화면의 최대
OBJ 수는 선행 점멸 포함 30개, 줄당 최대 9개다. 호스트 9검사도 통과했다.

자동 재생 밀집 29의 비용은 다음과 같다. 원작의 27회 마법 유지/종료와 선행
8회 점멸을 보존하지만, **시간상 원작 속도에 미달하며 정상 사용 경로로 승격하지 않는다.**

| 고정 MesenCore 측정 | 결과 |
|---|---:|
| 전체 행동 35게시 | 5,543.654ms |
| 첫→마지막 실제 DMA | 5,022.814ms |
| 최대 DMA 간격 | 2,779.052ms |
| 초기 준비 뒤 그림 교체의 최대 간격 | 368.373ms |
| 준비 완료→DMA 최대 | 16.788ms |
| 일반 준비 비용 | 2,994.086ms |
| 오디오 생산 / IRQ / 게시 대기 | 1,829.494 / 514.071 / 202.898ms |

타일쌍 사이 오디오 보충과 줄 카운터 변경 전에는 실제 부족이 검출됐다. 이를
검사 예외로 숨기지 않고 고쳤다. 최종 화면 2회 및 자동 재생 1회는 각각 7,200틱
전체에서 부족/지연 0이며, 화면 복구와 VRAM/OAM 안전 검사도 통과했다.
초기 smoke의 35화면/7,200틱은 위 합계에 중복하여 더하지 않는다.

좌우·상하 반전의 네 조합을 사용하는 원작 보통 마법 50도 정면과 백어택/상태 혼합에서
54화면이 일치했다. 각각 7,200틱 전체 오디오와 자원 복구를 검사했다.
공통 표시 회귀에서는 정면/백어택의 봉 공격+9999 숫자 116화면과 백어택의
적 점멸·피격/감싸기+숫자 128화면이 일치했다. 각각 7,200틱 오디오와 버스 안전도
통과했다. 기존 양손 봉 자동 재생도 2,110.163ms·최대 DMA 간격 83.956ms로
기준선을 유지했다. 이를 포함한 합계는 **742화면·8회 57,600틱**이며, 모든
무기/마법의 정상 진행을 재검사했다는 뜻은 아니다.

공개 소스 621개만 별도 디렉터리로 복사한 빌드에서 ROM·시험 기대값·불변 자원
등 9산출물과 마법 88레코드가 바이트 단위로 일치했다. 자료 출처/현재 지원 범위의
메타데이터 갱신은 동일 산출물 수에 넣지 않았다. 고정 WRAM 끝은 `$CF66`로
154바이트가 남으며, 진단 ROM은 은행 69까지 사용하여 2MiB로 확장된다.

다음은 signed BG 동결/VRAM 백업과 타일쌍 준비를 원작 상주 수명에 맞춰 개선하는
작업이다. 매번 VRAM에서 읽는 대신 정본 패턴을 보관하는 방법, 타일쌍의 공유 사전,
일부 아군만 동결하는 방법을 CPU/전송/WRAM 총비용으로 비교한다. 명중이 없을 때의
불필요한 대여도 제거 후보다. 이후 아군 시전/발사·적 대상·반사·특수/소환으로 간다.
R2 통합 0/8·제품 0/3은 유지하며, 정상 계산·상태 확정/사망은 별도 관문이다.
