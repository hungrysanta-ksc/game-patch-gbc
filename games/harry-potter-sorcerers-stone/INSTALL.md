# 패치 설치 안내 — 1.0.0

BPS 한 종류에 일반 플레이와 선택형 치트 메뉴가 함께 들어 있습니다.

## 지원 원본

| 항목 | 값 |
|---|---|
| 게임 | Harry Potter and the Sorcerer's Stone |
| 기종 | Game Boy Color |
| 버전 | USA/Europe 다국어판, revision 0 |
| 언어 표기 | En,Fr,De,Es,It,Nl,Pt,Sv,No,Da,Fi |
| 원본 크기 | 4,194,304바이트 (4 MiB) |
| 원본 SHA-256 | `8eb56e0d55a04aa3fcf940f172757f4f60baa6c53c82707def8ae4e78844b1da` |

파일명만으로는 지원 여부를 알 수 없습니다. 다른 판본이나 이미 수정된 ROM은 지원하지 않습니다. 원본 ROM과 적용 도구는 배포 파일에 포함하지 않습니다.

## 적용

1. 원본 ROM과 세이브를 백업하고 ROM의 압축을 풉니다.
2. 릴리즈의 ZIP을 풀어 `hp-ss-gbc-v1.0.0.bps`를 준비합니다.
3. [Floating IPS v198](https://github.com/Sir-Walrus/Flips/releases/tag/v198)을 실행하여 **Apply Patch**를 선택합니다.
4. BPS, 지원 원본 ROM 순서로 선택합니다.
5. 결과를 원본과 다른 이름으로 저장합니다. 예: `HP_SS_KO_1.0.0.gbc`.
6. 아래 크기와 SHA-256을 확인한 뒤 결과 ROM을 새로 실행합니다.

PowerShell에서 해시를 확인하는 예입니다.

```powershell
Get-FileHash -LiteralPath 'C:/Games/HP_SS_KO_1.0.0.gbc' -Algorithm SHA256
```

| 적용 결과 | 값 |
|---|---|
| 크기 | 4,194,304바이트 |
| ROM SHA-256 | `02960257a34718339076e484cd3a8f7c924b6d22b5ba708d65db60cae3d3d22b` |

이 해시는 ZIP이나 BPS의 해시가 아닙니다. 패치 파일의 해시는 ZIP 안의 `release-manifest.json`에 있습니다. 원본 불일치 오류를 무시하거나 이전 한글판에 덧씌우지 마세요.

## 기존 저장 파일

게임 내 저장 기능의 `.sav`/`.srm`을 백업하고, 사용하는 에뮬레이터가 요구하는 파일명과 위치에 복사하세요. 보통 ROM과 저장 파일의 이름 부분을 같게 맞춥니다.

새 ROM을 부팅한 뒤 **게임 내 이어하기**를 사용하세요. 이전 빌드에서 만든 강제 저장 상태(save state)는 코드·화면 메모리를 함께 복원하므로 사용하지 마세요.

내부 v026 세이브로 로드·획득·저장·리셋·재로드를 Gambatte와 VBA-M에서 확인했습니다. 모든 기기와 이전 버전의 저장 파일을 검증한 것은 아닙니다. 과거 내부판에서 손상된 특정 기숙사 점수는 일반 저장 파일 로드 시 해당 손상 패턴이 일치할 때만 복구합니다.

## 추가 기능

- 다국어 선택을 제거하고 한국어로 고정했습니다. (용량확보)
- 필드에서 B를 누른 채 이동하면 두 배 속도로 달립니다.
- START 메뉴에서 레벨·체력(SP)·마력(MP)을 확인할 수 있습니다.
- 메뉴와 전투가 마지막 커서 위치를 기억합니다.
- 전투 중 대기 시간과 일부 연출을 수정해 속도를 개선했습니다.
- 필드에서 획득할 수 있는 아이템이 화살표로 표시합니다.
- 치트 기능을 추가했습니다.

## 치트 메뉴

필드에서 **START + SELECT**를 함께 누르면 치트 메뉴가 열립니다.

- 경험치 3배: 켜기/끄기
- 시클 3배: 켜기/끄기
- 주문 전체 습득
- 카드 전체 습득

옵션과 습득 결과는 게임 내 저장에 반영되므로 먼저 세이브를 백업하세요.

## 표시 및 검증 범위

대사·메뉴 등 English-US 슬롯의 3,063개 문자열을 대상으로 번역 및 공백 보존을 적용했습니다. 원래 영문으로 유지하도록 지정한 저작권 고지, 로고와 MENU/FOLIO 등의 일부 이미지 문자는 영문으로 표시됩니다.

자동 검증은 원본 지문, 쓰기 충돌, 등록된 메모리 배치, 글리프와 문자열, BPS 적용 결과를 확인합니다. 주요 플레이 회귀는 Gambatte와 VBA-M에서 수행했습니다. 모든 기기·진행 상태의 무결점 보증이나 별도의 전체 플레이 횟수 주장은 하지 않습니다.

BPS는 게임 파일이 아니므로 에뮬레이터에서 바로 실행할 수 없습니다. 오류 제보 시 버전·실행 환경·재현 순서·결과 ROM 해시를 함께 알려 주세요.
