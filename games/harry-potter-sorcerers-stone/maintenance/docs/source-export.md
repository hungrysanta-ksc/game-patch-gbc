# 공개 소스와 로컬 입력

이번 공개는 사용자의 1.0.0 배포·소스 정리 요청에 따른 것이다. 원래 개발 폴더의 Git 이력이나 work/out 전체를 가져오지 않고, 검토한 파일 목록과 해시를 내보낸다.

## 공개한 항목

- 누적 빌드에 쓰이는 Python/SM83 ASM 전부 및 일부 과거 경로의 원천.
- 원본 구조, 메모리 ledger, 릴리즈 명세. 문구 포함 runtime profile은 제외.
- 원본 추출·번역 가져오기·런타임/단일 BPS 패키지 생성 도구.
- 안정된 경계 검사, CPU/코어 재생 하네스, 필요한 재현 입력.
- 현재 구조와 실제 실패에서 얻은 지식, 검증 범위, 사용자 제공 스크린샷 10장.

스크린샷은 screen.zip의 PNG를 크기·색상·내용 변경 없이 복사했다. 원본 게임 그래픽 덤프나 영상 전체가 아니다.

## 별도 입력

config/release-v1.0.0.json의 private_inputs는 경로·해시만 기록한다. config/runtime-v027.json에는 사용자 번역 문구가 있어 공개하지 않는다. 승인 TSV/translation.json에는 원문과 번역이 있어 공개하지 않는다. 폰트와 그 파생 타이틀 판도 로컬 입력으로 분리한다. 이 파일들을 보유하지 않은 공개 소스 체크아웃은 소스 검사와 도구 재사용은 가능하지만 동일 번역 ROM을 빌드할 수 없다.

비공개 폴더라는 이름이 GitHub의 부분 접근 제어를 뜻하지 않는다. 파일은 실제 Git 제외 규칙과 명시 파일 목록으로 제외한다. 원본·패치 ROM·SAV·강제 저장 상태·원문 덤프·전체 메모리 캡처·실행 파일·자격증명은 내보내지 않는다.

## 과거 조사 기록

research의 일부 검사는 v010/v011, v025/v026 내부 결과를 전제로 한다. 과거 게임 상태, 과거 private profile과 산출물은 공개물에 없으며 실행 조건을 README/BUILD.md에 구분했다. 원본/번역 전체나 개인 경로를 노출하는 일회성 작업 덤프는 공개하지 않는다.

export-manifest.json은 이 게임 폴더의 공개 파일과 해시를 기록하며 자기 자신은 해시 순환을 피하기 위해 제외한다. 공개 전 목록과 실제 Git 변경 파일을 대조한다. 패치 ZIP은 Git 소스 이력 대신 Release 첨부파일로 배포한다.
