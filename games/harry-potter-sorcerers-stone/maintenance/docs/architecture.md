# 런타임 구조

## 원본 및 주소

지원 대상은 source-profile.json의 4 MiB USA/Europe ROM 하나다. CPU 은행 주소와 파일 offset을 구분한다. 교체 지문은 해당 판본에만 유효하며 후속작의 주소를 가져다 쓰지 않는다.

English-US descriptor는 은행 20h의 4001h..63E5h에 3,063개가 있다. 각 항목은 bank 증가값 1바이트와 little-endian 주소 2바이트다. 원본 Huffman 비트는 LSB 우선, leaf의 상위 비트는 표식, 종료 코드 7Fh다. native decoder는 마지막 출력 문자의 상위 비트를 켠다. 00:300A resolver와 00:3633 decoder의 지문을 text-format.json에서 검사한다.

extract_source.py는 모든 의미 비트를 다시 인코딩하고 마지막 바이트의 비소비 비트를 보존한다. 재삽입한 전체 원본이 바이트 동일해야 한다. 이것은 원본 구조 왕복 검증이며 번역 장면 검수를 대신하지 않는다.

## 한글 공급과 변수

2,350개 완성형 글리프의 8바이트 마스크를 native 합성에 공급한다. 인코딩, 가변 문자열 읽기, 단어 폭, 직접 출력, 지연 descriptor 경로를 함께 수정한다. 한 경로만 바꾸면 글자는 보여도 줄바꿈이나 변수 치환이 깨질 수 있다.

WRAM7의 D800은 치환 전 문자열, D400은 치환 후 문자열이다. 각 버퍼는 1,024바이트다. 고정 16바이트 변수 슬롯에는 긴 한글 문자열 대신 3바이트 지연 descriptor를 보관한다. 숫자 슬롯의 최대값과 문자열 슬롯의 최대 길이를 구분해 빌드에서 최종 확장 상한을 검사한다.

폴리오 설명의 첫 두 공백과 줄바꿈은 소비자가 미리 건너뛰는 구조다. 텍스트 정리 과정에서 제거하면 첫 한글의 일부가 사라진다. 공백은 의미 없는 장식으로 일괄 정리하지 않는다.

## 4 MiB 재배치

선택 언어를 20h로 고정하고 폐기한 언어 26h/2Ch/33h의 descriptor·스트림 전체를 파싱하여 은행 26h..39h를 분류한다. 은행 태그를 보존하고, 본문과 글꼴·코드의 구역을 나눈다. 본문은 2A:4001부터 39은행 앞까지 배치한다. 문자열이 은행 끝을 넘으면 다음 은행의 태그 다음에서 시작한다.

src/compact_runtime.py와 build_runtime.py가 이 경계를 검사한다. 원본 지도 데이터의 좌표 수정처럼 언어 풀 밖의 의도된 쓰기는 검토한 정확한 레코드만 예외로 허용한다.

## 메뉴·전투·치트

상태 패널은 native 메뉴 배경 팔레트를 유지하며 64픽셀 폭으로 이름·SP·MP를 합성한다. 타일 24개와 타일맵 24칸의 소비 범위를 제한한다. 커서는 사용할 수 있는 항목인지 다시 확인한 뒤 복원하며 새 게임/부팅에서 초기화한다.

치트 진입은 원래 디버그 입력 처리 지점을 사용한다. 폐기한 장소 이동 메뉴의 함수만 교체하고 게임 이벤트가 사용하는 워프 표를 보존한다. 네 기능은 경험치·시클 배율 옵션과 주문·카드 전체 습득이다. 배율은 태그가 유효할 때만 읽으며 실제 보상 계산을 거쳐 적용한다.

## 필드 표시

원본 액터가 만든 OAM 뒤의 남은 엔트리에 기존 공용 대화 화살표를 추가한다. 장소별 배경/스프라이트 타일을 가져다 쓰지 않는다. 이벤트 진행 중에는 표시하지 않으며 독립적인 영구 RAM을 추가하지 않는다.

아이템 07, 조합 0A, 약초 70, 검증한 이벤트 보상 0C 등의 원래 소비 조건을 각각 적용한다. 세부 조건과 실제 위치 문제는 bugs-and-regressions.md를 따른다.
