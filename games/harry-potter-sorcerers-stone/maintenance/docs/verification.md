## 기계적 검증

- 원본 크기·강한 지문·헤더/전체 체크섬.
- English-US 3,063개 descriptor의 의미 비트 재인코딩과 원본 전체 동일성.
- 미등록 글리프, 변수 확장 상한, 은행 경계, 원본 지문, writer 중첩, 최종 미등록 diff 거부.
- ASM→기계어→역해석→재조립 왕복.
- 비본문 쓰기 160개와 RAM 영역 21개 등록·내용 해시·보호 표 검사.
- BPS를 원본에 다시 적용하여 검증된 ROM과 전체 바이트 동일성.
- 잘못된 원본 및 손상된 패치가 성공 출력으로 남지 않는지 확인.
- ZIP 파일 명시 목록·내용·체크섬 검사와 새 작업폴더에서 같은 결과 재현.

`config/release-v1.0.0.json`은 고정 릴리즈의 출력 지문을 검사한다. 후속 릴리즈는 이 값을 조용히 갱신하는 대신 새 승인 명세로 분리한다.

## 누적 실행 근거

v026에서 점수/저장·리셋, 금고 동행, 도서관 주문·제조법, 메뉴·아이템·폴리오, 전투 명령, 치트, 약초·카드 조합을 두 코어 각각 13경로로 재생했다. 이때 코드 보존과 스택 표식을 관측했다. v027과 실행 코드는 동일하므로 동일 코드의 기존 관측 근거로 유지하되 v027에서 26경로를 새로 실행한 것으로 쓰지 않는다.

v027에서는 다음을 별도로 확인했다.
- 세이브부터 일반 입력만으로 숲의 첫 지점 획득·저장·리셋·재로드: 두 코어, 각 8,900프레임.
- 수정 지점 5곳 × 두 코어: 각 4,500프레임. 맵/위치를 준비한 로컬 세이브에서 시작한 통제 전제이다.
- 미획득 14개 장소의 접근: 통제 위치와 적 액터 제거 하네스를 사용한 PyBoy 검사.
- 다섯 지점의 표식 OAM 존재→제거→메뉴 복귀 후 제거 상태: 적 제거 없는 별도 검사.
- 해당 보상 수량 +1과 해당 발견 슬롯 FF 외 WRAM6 차이가 없음을 대조.

공개 재생 입력은 research/routes에 있으며 개인 SAV와 화면/RAM 전체 덤프는 제외했다. 조건이 다른 세이브로 같은 입력을 실행하는 것은 같은 검사가 아니다.

## 남은 한계

이 릴리즈는 데이터 문자열 한글화를 중심으로 한다. 저작권 고지 중 원문 유지 요청분, 로고·MENU·FOLIO 등 일부 이미지 문자는 영문이다. 사용하지 않는 좌표 템플릿 2320의 숫자 계약은 정적 가정이 남아 있으며 활성 호출 경로가 확인되지 않았다.

전체 게임의 모든 간접 메모리 접근, 호출 깊이, 통신·미니게임, 모든 VBA 파생 버전과 실기 호환성을 증명한 것은 아니다. 알려진 재현 문제의 수정과 관측한 경로의 검증을 이 범위와 구분한다.
