# 변경 내역

## 1.0.0 — 2026-11-22

첫 정식 배포. 내부 v027과 같은 게임 내용을 단일 BPS로 제공합니다.

## 추가 기능

- 다국어 선택을 제거하고 한국어로 고정했습니다. (용량확보)
- 필드에서 B를 누른 채 이동하면 두 배 속도로 달립니다.
- START 메뉴에서 레벨·체력(SP)·마력(MP)을 확인할 수 있습니다.
- 메뉴와 전투가 마지막 커서 위치를 기억합니다.
- 전투 중 대기 시간과 일부 연출을 수정해 속도를 개선했습니다.
- 필드에서 획득할 수 있는 아이템이 화살표로 표시합니다.
- 치트 기능을 추가했습니다.

## 치트 메뉴

필드에서 **START + SELECT**를 함께 누르면 치트 메뉴가 열립니다.

- 경험치 3배: 켜기/끄기
- 시클 3배: 켜기/끄기
- 주문 전체 습득
- 카드 전체 습득

옵션과 습득 결과는 게임 내 저장에 반영되므로 먼저 세이브를 백업하세요.

## 누적 수정 기록

플레이 중 지적된 번역 교정을 누적 반영했습니다. 폴리오 설명의 구조 공백, 이벤트 워프 표와 커서 코드 충돌, 기숙사 점수 표의 FF 데이터 오인, 덱별 카드 조합의 표시 조건, 퀘스트 재료·주문·제조법의 표시 조건을 수정했습니다. 마지막으로 금지된 숲 6개 구역에서 남은 보상 14개를 조사하여 5곳의 조사 좌표를 보정했습니다.

내부 개발 이력과 검사 범위는 저장소의 유지보수 문서에서 확인할 수 있습니다.
