# 패치 설치 안내

공개 버전 **v0.8.1** / 내부 빌드 **v140** 기준입니다. 일반판(normal)과 디버그판(debug)을 함께 배포합니다.

## 준비물

- 정품 게임을 보유하고 적법하게 준비한, 아래 지원 버전에 해당하는 원본 ROM
- 이 프로젝트의 BPS 패치
- [Floating IPS v198](https://github.com/Sir-Walrus/Flips/releases/tag/v198)
- 게임보이 컬러 게임을 실행할 환경

이 안내는 Windows용 Floating IPS를 기준으로 작성했습니다. 적용 도구와 에뮬레이터는 패치에 동봉하지 않습니다.

## 지원 원본

| 항목 | 값 |
|---|---|
| 게임 | Harry Potter and the Chamber of Secrets |
| 기종 | Game Boy Color |
| 버전 | USA/Europe 다국어판, revision 0 |
| 원본 크기 | 4,194,304바이트 (4 MiB) |
| 원본 SHA-256 | `2788df60fc6373bdf7c9fa241a4409da14726f23017953adc1121bb90ad6b99a` |

파일명만으로는 지원 여부를 확인할 수 없습니다. 이미 패치된 파일이나 다른 버전에는 적용하지 마세요. 압축 파일이라면 먼저 ROM을 압축 해제하고 확인하세요.

Windows PowerShell에서 파일의 SHA-256을 확인할 수 있습니다. 아래 경로는 자신의 파일 경로로 바꿔 주세요.

```powershell
Get-FileHash -LiteralPath 'C:\Games\original.gbc' -Algorithm SHA256
```

해시의 대문자·소문자는 구분하지 않습니다.

## 적용 순서

1. 게임과 에뮬레이터를 종료하고 원본 ROM 및 세이브 파일을 별도 폴더에 백업합니다.
2. 릴리스 첨부파일을 받아 압축을 풉니다. 일반 플레이에는 `normal`로 표시된 BPS를 선택합니다.
3. Floating IPS를 실행하고 **Apply Patch**를 선택합니다.
4. 적용할 `.bps` 파일을 선택한 다음, 수정되지 않은 원본 ROM을 선택합니다.
5. 결과 파일을 원본과 다른 이름으로 저장합니다. 예: `HP_COS_KO_v0.8.1_normal.gbc` 또는 `HP_COS_KO_v0.8.1_debug.gbc`.
6. 아래 표와 결과 파일의 크기·SHA-256이 일치하는지 확인합니다.
7. 결과 파일을 실행합니다. 별도의 언어 선택 없이 한국어로 시작합니다.

일반판과 디버그판은 각각 원본에 적용하는 대안입니다. 서로 겹쳐 적용하거나 이전 한글판에 덧씌우지 마세요. 원본 불일치 오류가 나면 검사를 무시하지 말고 파일의 해시부터 확인하세요.

## 적용 결과 확인

두 결과 파일 모두 4,194,304바이트입니다.

| 종류 | 적용 후 ROM의 SHA-256 |
|---|---|
| 일반판 | `4831a6b99c7a631b374221b3206be711f8a79d5e643fb8170098293e1600a370` |
| 디버그판 | `b2581ff5b455de219861b51144253ef7a0cb5ccda8573d0379b7c35bc21e1bcf` |

위 값은 BPS나 ZIP이 아닌 **적용 후 ROM 파일**의 해시입니다.

## v0.8.1 업데이트

서점 NPC 오류를 수정한 버전입니다. 이전 강제 저장에는 잘못된 NPC 상태가 포함될 수 있으므로 게임을 새로 부팅하고 게임 내 이어하기를 사용하세요.

## 기존 세이브 사용

게임 안의 저장 기능으로 만든 `.sav`/`.srm` 파일은 먼저 백업하고 사본으로 시도하세요. 사용하는 에뮬레이터의 저장 경로·이름 규칙에 맞춰야 합니다. 모든 이전 버전과 실행 환경 사이의 호환성을 보장하지는 않습니다.

다른 버전에서 만든 강제 저장 상태(save state)는 사용하지 말고, 게임을 새로 부팅한 뒤 게임 내 이어하기를 사용하세요. 디버그판을 시험할 때에는 일반 플레이용 세이브와 별도 사본을 사용하세요.

패치를 제거하려면 백업한 원본 ROM으로 돌아가세요. 세이브는 덮어쓰기 전에 다시 백업하세요.

## 디버그판을 사용하는 경우

필드에서 **SELECT + START**를 함께 누르면 원본 CHEAT 메뉴에 들어갑니다. 방향키와 A로 선택하고 B로 취소·복귀합니다. 메뉴를 열었다고 치트가 자동 적용되지는 않습니다.

지도·이벤트·아이템 조작은 게임 진행에 영향을 줄 수 있습니다. 모든 디버그 명령의 동작을 검수한 것은 아니므로 일반 플레이에는 일반판을 권장합니다.

## 자주 묻는 질문

**BPS 파일을 에뮬레이터에서 바로 실행할 수 있나요?**

BPS는 게임 파일이 아닙니다. 위 순서로 원본 ROM에 적용한 뒤 결과 ROM을 실행하세요.

**패치 적용에 실패합니다.**

원본의 압축을 풀었는지, SHA-256이 일치하는지, 다른 패치가 적용되지 않았는지 확인하세요. 계속 실패하면 패치 버전과 오류 메시지를 제보해 주세요.

**이전 버전의 세이브를 불러오면 화면이 이상합니다.**

강제 저장 상태 대신 새로 부팅한 뒤 게임 내 저장을 불러오세요. 같은 문제가 계속되면 사용 환경과 재현 순서를 알려 주세요.

**100% 번역·완주 검수가 끝난 버전인가요?**

아닙니다. 현재는 베타이며 전체 완주·모든 분기·실기 검수는 끝나지 않았습니다. 이미지에 포함된 문구 등은 원문으로 남을 수 있습니다.
