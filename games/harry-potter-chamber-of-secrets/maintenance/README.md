# K157 유지보수 소스

정식판 v1.0.0의 마지막 수정과 독립적으로 재사용할 수 있는 Python 모듈을 보관한다. 이 폴더의 코드에 적용되는 조건은 [LICENSE](LICENSE)에 있다.

- `src/hangul.py`는 유니코드 완성형 한글을 초성·중성·종성 인덱스로 분해한다.
- `src/tile2bpp.py`는 GB의 8×8 타일을 16바이트와 픽셀 배열 사이에서 변환한다. 합성 시 덧그릴 타일의 색인 0은 투명하게 처리한다.
- `src/sm83_poc_assembler.py`는 패치에서 사용하는 SM83 명령 부분집합을 조립하고 결과를 역변환한다.
- `research/build_duel_scroll_v157.py`는 K156의 일반판·디버그판을 입력으로 받아 전투 커서 데이터와 결투 화면 효과의 WRAM 충돌을 해결한다. 두 스택 초기화 지점과 커서 초기화·읽기·쓰기를 함께 바꾼 뒤 체크섬을 갱신한다.

K156 내부 빌드를 보유한 유지보수자는 이 폴더에서 `out/internal-v156/`에 파일명에 각각 normal, debug가 들어간 K156 GBC 파일을 하나씩 놓고 `python research/build_duel_scroll_v157.py`를 실행한다. 기본 Python 모드에서 실행해야 입력 해시와 기존 명령 검사가 동작한다. 결과는 `out/internal-v157/`에 생긴다. 출력 이름은 입력 파일명의 156을 157로 바꾼 값이다. 결과 해시는 [설치 안내](../INSTALL.md)와 대조한다. 원본 게임에서 시작하는 사용자는 같은 안내의 BPS 적용 절차를 따른다.

독립 모듈 테스트는 이 폴더에서 `python -m pytest tests`로 실행한다.
