# 변경 내역

## v1.0.0 (내부 빌드 K157)

교정과 검수를 마치고 엔딩까지 두 차례 플레이한 정식 버전입니다.

- 필드에서 B를 누른 채 이동하면 두 배 속도로 달립니다. START 메뉴에서 최대 세 명의 레벨·체력·마력을 확인할 수 있습니다.
- 호그와트 성 안에서 SELECT+B로 지도를 엽니다. 지하부터 7층까지 방 이름을 한글로 표시하고 출입구가 보이도록 배치했습니다.
- 전투에서 주문 전후의 대기와 반복 연출을 줄이고 투사체의 이동과 적중 시점을 조정했습니다.
- 아이템 메뉴와 전투 주문 메뉴가 마지막 선택을 기억합니다. 전투에서는 캐릭터별로 기억하며 사용할 수 없는 항목은 기본 위치로 돌아갑니다.
- 말포이 결투에서 ‘마력 불어넣기’ 다음에 ‘엑스펠리아르무스’를 쓰면 하단 메뉴가 겹치던 문제를 수정했습니다.
- 저장 완료 메시지, 이벤트 보상 화면, 예·아니오 커서 표시를 다듬고 대사를 교정했습니다. 타이틀 화면에 한글판 표기를 추가했습니다.

## v0.8.1 — 2026-09-18 (내부 빌드 v140)

- 서점 상단 이벤트를 마친 뒤 아래로 내려왔을 때 루시우스 말포이와 다른 NPC가 나타나지 않아 진행이 막히던 문제를 수정했습니다.
- 메뉴를 열었다 닫아야 NPC가 나타나던 현상을 수정했습니다. 한글 처리 코드가 NPC 상태 메모리를 덮어쓰지 않도록 실행 방식을 변경했습니다.
- 원본 그래픽, 번역 내용, 글꼴 및 4 MiB 크기를 유지합니다. 일반판과 디버그판에 동일하게 적용했습니다.
- 해당 이벤트의 후속 진행과 사용자 재확인을 마쳤습니다. 문자열·글리프·변수 치환, 대화창 화면 갱신 및 패치 적용 결과도 검사했습니다. 전체 완주·모든 분기·실기 검수는 계속 진행 중입니다.

### 업데이트 시 주의

기존 한글 ROM에 덧씌우지 말고 지원하는 수정되지 않은 원본 ROM에 새 BPS를 적용하세요. `.sav`/`.srm`은 백업한 사본을 사용하고 게임을 새로 부팅해 이어하기를 선택하세요. 이전 버전의 `.sgm` 등 강제 저장에는 이미 잘못된 NPC 상태나 구형 실행 코드가 남아 있을 수 있으므로 업데이트 검증에는 사용하지 마세요.
