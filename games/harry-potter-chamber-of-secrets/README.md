# 해리 포터와 비밀의 방 GBC 한글 패치

[전체 GBC 패치 목록](../../README.md)

> 공개 버전 v1.0.0 / 내부 빌드 K157

게임보이 컬러용 **Harry Potter and the Chamber of Secrets**를 한국어로 즐기기 위한 비공식 팬 번역 패치입니다.

**배포 파일은 BPS 패치와 사용 안내입니다.** 게임 원본 ROM, 패치가 적용된 ROM, ROM 다운로드 링크는 제공하지 않습니다. 정품 게임을 보유하고 적법하게 준비한 지원 버전의 원본 파일이 필요합니다.

## 다운로드

[v1.0.0 릴리스](https://github.com/hungrysanta-ksc/game-patch-gbc/releases/tag/hp-cos-gbc-v1.0.0)에서 일반판·디버그판 패치 ZIP을 받으세요.

**일반판(normal)과 디버그판(debug)을 함께 배포합니다.** 일반 플레이에는 일반판을 사용하세요. 디버그판은 테스트 용도이며, 일반판과 겹쳐 적용하지 않습니다.

## 정식판 변경 사항

교정과 검수를 마치고 엔딩까지 두 차례 플레이한 정식 버전입니다.

- 필드에서 B를 누른 채 이동하면 두 배 속도로 달립니다. START 메뉴에서 최대 세 명의 레벨·체력·마력을 확인할 수 있습니다.
- 호그와트 성 안에서 SELECT+B로 지도를 엽니다. 지하부터 7층까지 방 이름을 한글로 표시하고 출입구가 보이도록 배치했습니다.
- 전투에서 주문 전후의 대기와 반복 연출을 줄이고 투사체의 이동과 적중 시점을 조정했습니다.
- 아이템 메뉴와 전투 주문 메뉴가 마지막 선택을 기억합니다. 전투에서는 캐릭터별로 기억하며 사용할 수 없는 항목은 기본 위치로 돌아갑니다.
- 말포이 결투에서 ‘마력 불어넣기’ 다음에 ‘엑스펠리아르무스’를 쓰면 하단 메뉴가 겹치던 문제를 수정했습니다.
- 저장 완료 메시지, 이벤트 보상 화면, 예·아니오 커서 표시를 다듬고 대사를 교정했습니다. 타이틀 화면에 한글판 표기를 추가했습니다.

## 시작하기

1. 원본 ROM과 기존 세이브를 백업합니다.
2. [설치 안내](INSTALL.md)에서 원본 파일의 버전과 SHA-256을 확인합니다.
3. Floating IPS로 BPS 패치를 원본에 적용하고 새 파일로 저장합니다.
4. 패치된 파일을 새로 실행합니다. 다른 버전에서 만든 강제 저장 상태는 불러오지 마세요.

자세한 적용 순서, 해시 확인법, 세이브 안내는 [INSTALL.md](INSTALL.md)를 참고하세요.

## 오류 제보

[Issues](https://github.com/hungrysanta-ksc/game-patch-gbc/issues)에 다음 정보를 남겨 주세요.

- 패치 버전과 일반판/디버그판 여부
- 사용 기기 또는 에뮬레이터 이름·버전
- 문제가 발생한 장소와 직전 행동, 다시 발생시키는 순서
- 기대한 결과와 실제 결과
- 가능하면 문제가 보이는 화면과 패치된 ROM의 SHA-256

공개 게시물에는 ROM 파일, 게임 전체 대사 파일, 세이브 파일을 첨부하지 마세요. ROM 입수처 문의는 받지 않습니다.

## 이용 및 공유 안내

이 패치는 무료로 제공하는 비상업적 팬 프로젝트입니다. 패치의 판매, 유료 배포, 패치된 ROM이나 게임기·카트리지와 묶은 판매에 사용하지 말아 주세요.

다른 곳에 소개할 때에는 최신 버전과 수정 사항을 확인할 수 있도록 이 저장소 또는 릴리스 페이지의 링크를 공유해 주세요.

게임과 해리 포터 관련 저작물·상표의 권리는 각 권리자에게 있습니다. 본 프로젝트는 EA, Warner Bros., J.K. Rowling 또는 관련 권리자와 제휴하거나 이들의 후원·승인을 받은 프로젝트가 아닙니다. 원작 및 제3자 자산의 이용 권한을 별도로 부여하지 않습니다.

권리 관련 문의는 저장소 운영자에게 연락해 주세요. 권리자의 요청이 있는 경우 내용을 확인하여 수정 또는 배포 중단 등 필요한 조치를 취하겠습니다.

**기술적 문제나 권리 관련 문제 등으로 패치 배포가 언제든지 중단될 수 있습니다.**
