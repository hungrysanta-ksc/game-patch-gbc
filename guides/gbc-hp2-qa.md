# 비밀의 방 정식판에서 이어지는 GBC 한글화 검수

비밀의 방 K157(v1.0.0)은 일반판과 디버그판을 따로 검수했다. 후속 게임에서 재사용할 수 있는 것은 [타일·한글 도구와 최종 수정 예제](../games/harry-potter-chamber-of-secrets/maintenance/) 및 아래 재현 절차다. 메모리 주소, 폰트 폭, 언어 슬롯, 세이브 형식은 각 게임에서 다시 조사한다.

| 비밀의 방 사례 | 후속 게임에서 확인할 것 |
| --- | --- |
| 한글 대사의 줄 끝 음절과 따옴표가 잘림 | 초상화 너비와 좌측 여백을 적용한 실제 그리기 폭을 줄바꿈 계산과 대조한다. 마침표 앞 음절, 수동 줄바꿈, 다음 페이지 첫 줄을 캡처한다. |
| 메뉴 복귀 후 서점 NPC 표시가 달라짐 | 이벤트 직전의 같은 게임 내 저장을 복사해 메뉴 없이 진행하는 경로와 메뉴를 열고 닫는 경로를 비교한다. 등장 여부와 다음 이벤트 진행을 모두 확인한다. |
| 전투 가속 중 투사체가 중간에서 폭발 | 시전, 발사, 적중, 다음 입력까지 구간별로 시간을 잰다. 궤적과 적중 위치를 먼저 맞추고 반복 대기를 조정한다. 연속 투사체·전체 화면 기술도 따로 본다. |
| 커서 기억과 결투 화면 효과가 같은 WRAM을 사용 | 한 장면에서 비어 보이는 바이트의 읽기·쓰기를 메뉴·전투·화면 효과에서 추적한다. 캐릭터 변경, 마지막 아이템 소모, 카드 기술 직후 주문까지 조합해서 시험한다. |
| 메뉴·선택창에서 글자와 아이콘이 겹침 | 예/아니오 양쪽, 저장 메시지, 최대 파티, 지도 출입구를 게임 해상도에서 확인한다. |

배포 전에는 지원 원본의 크기와 SHA-256을 고정한다. 깨끗한 원본에 일반판·디버그판 BPS를 각각 적용해 검수 ROM의 SHA-256과 비교한다. 실제 사용한 빌드, 코어, 저장 슬롯, 재현 입력을 기록하면 다음 게임에서도 결과를 구분할 수 있다.
